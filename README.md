**EcoPilot AI**

Energy and carbon optimization platform using machine learning to analyze household energy usage and suggest efficient appliance scheduling.
**Features**
Energy & carbon analysis
Time-based carbon scoring
Appliance optimization
VPP simulation
Naive Bayes chatbot
Local ML processing
Tech Stack
React.js, Vite, Tailwind CSS
Python, Flask
Linear Regression, Naive Bayes
JSON, Synthetic Data

**Run Locally**

**1. Backend**
cd backend
python app.py

**2. Frontend**
cd frontend
npm install
npm run dev

**3. Open**
http://localhost:5173
